# CMOS Logic Gates in Electric VLSI

Two introductory transistor-level CMOS gate projects created in Electric VLSI, with schematic and layout SPICE exports simulated in LTspice.

| Project | Function | Documentation |
| --- | --- | --- |
| CMOS NOT | `Y = ¬A` | [Design and truth table](https://github.com/solehahnajiihah/IC_Design_Layout/tree/main/CMOS_NOT) |
| Two-input CMOS NAND | `Y = ¬(A · B)` | [Design and truth table](https://github.com/solehahnajiihah/IC_Design_Layout/tree/main/CMOS_NAND) |

Each project README lists its simulation files, setup, and current verification limits.
